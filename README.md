# StudyOS Landing

Адаптивный лендинг образовательного продукта StudyOS на Next.js, TypeScript, Tailwind CSS и Lucide Icons.

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Проверки

```bash
npm run lint
npx tsc --noEmit
npm run build
```

## Стек

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Lucide Icons

Все пользовательские тексты на русском. Название StudyOS без перевода.
